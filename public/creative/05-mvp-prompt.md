# Pixel Night Run implementation prompt

Transform the existing AI Usage Chronicle into **THE ENDLESS BUILD — Pixel Night Run**, a personal AI-builder history presented as an original Beijing-night 2D platformer save file.

## Non-negotiable product rules

- Preserve the existing report structure, Codex / Cursor / Claude Code / One API data semantics, exact totals, cache accounting, costs, and URL state.
- Keep all-time as the default view.
- Show exactly one hero number, dynamically derived from lifetime recorded tokens. Directly disclose dynamic cache-reused tokens and ratio, and state that usage is not output or productivity.
- Use platform-game spatial language without copying Super Mario names, characters, sprites, blocks, coins, pipes, sounds, colors, or trade dress.
- Use a gold command cursor `>` as the player and a continuous route as the signature interaction.
- Retain the full loop: equip a tool → inspect models → Focus a model → synchronize chart, URL, visible selected state, and aria-live status.
- Keep the exact record value as a gold `RECORD` climax while removing visitor-facing `RECORD SKY`, `RECORD HORIZON`, and `GROUND / TOKENS PER DAY` labels.
- Derive Checkpoint Log facts only from published data. Do not invent XP, ranks, levels, streaks, unlocks, badges, or rewards.

## Required page sequence

1. Save cover: `THE ENDLESS BUILD`, live save state, lifetime score, cache disclosure.
2. `THE ENDLESS RUN`: daily stacked terrain on desktop, natural-week stacked terrain on mobile.
3. `LOADOUT STATION`: four tools with explicit equipped/pressed state.
4. `MODEL GATE`: inspect and Focus are distinguishable actions.
5. `CHECKPOINT LOG`: highest day, recorded days, tools used.
6. `EXACT LEDGER`: precise tooltips, costs, model details, and token parts.

## Interaction and quality gates

- Loading is a stable stage skeleton with `role=status`, `aria-live=polite`, and `aria-busy=true`.
- Error is a broken-route save state with `role=alert`, assertive announcement, and retry.
- All interactive controls have visible keyboard focus; Escape unwinds model panel, Focus, then tool selection one layer at a time.
- Focused model state remains deep-linkable and reload-safe.
- Reduced motion disables smooth/looped motion without hiding state changes.
- Mobile is a vertical journey, not a horizontally dragged desktop canvas.
- Do not hard-code observed token totals or ratios into UI source.
- Prefer existing dependencies and the simplest durable implementation; do not add a game engine.

## Completion evidence

- Frontend behavior tests cover the dynamic hero/cache disclosure, default all-time, original game language, hidden chart jargon, loading/error states, mobile/reduced-motion contracts, and the complete tool/model/Focus synchronization loop.
- `npm run test:frontend` passes remotely.
- `npm run build` passes remotely.
- Visual review confirms data readability and a coherent adult pixel-night identity at desktop and mobile sizes.
