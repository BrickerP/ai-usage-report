# Round 8 — 预设优先的时间控件

## 假设

大多数查看使用 7 / 30 / 90 天或 All；精确日期、整体平移区间与 Reset 属于低频操作。置信度：85%。

## 自问

应该删除低频日期功能、全部保留展开，还是让预设常驻、其余按需展开？

## 自答与选择

- 删除：最简，但会破坏已经存在的历史排查能力与 URL 自定义日期恢复。
- 全部展开：功能最显眼，却让 8 个控制点持续争夺注意力。
- 预设常驻、按需展开：日常路径短，精确控制仍完整。

选择第三种。四个预设始终可见；日期选择、Earlier、Later 与 Reset 进入 `Custom dates` 面板。

## 落地

- `Custom dates` 明确暴露 `aria-expanded` 与 `aria-controls`。
- 从带 `from/to` 的 URL 恢复视图时自动展开精确日期面板。
- 选择任一预设或 Reset 后收起面板，让页面回到简洁状态。
- Earlier / Later 的边界禁用、DateRangeInput 的 min/max 和 URL 序列化保持原样。

## 反思

这轮不是把高级能力藏到不可发现的菜单里，而是给它一个稳定、可命名的入口。默认视觉复杂度下降，状态恢复和键盘可达性没有下降。
