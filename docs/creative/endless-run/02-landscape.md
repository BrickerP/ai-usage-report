# Step 2 — Search and landscape

## References studied

These references inform principles only. No layout, artwork, sprites, branding, trade dress, or distinctive interaction is to be copied.

| Reference | What it demonstrates | Principle to borrow | What we will not copy |
| --- | --- | --- | --- |
| [Codex Resets](https://codex-resets.com/) | Live account data can become a compact, glanceable status | Immediate truth, clear timing, low-friction return visits | Brand, layout, copy, or status-card treatment |
| [How GitHub built the Skyline CLI extension](https://github.blog/developer-skills/application-development/how-we-built-the-github-skyline-cli-extension-using-github/) | Personal history can become an explorable spatial artifact | Geometry derived from real history; exploration reveals detail | GitHub contribution semantics, 3D Skyline form, CLI flow, or visual grammar |
| [Endigo gaming portfolio](https://endigodesign.com/works/gaming/portfolio/) | A game-inspired journey can organize otherwise ordinary sections | A legible route, staged disclosure, and a strong sense of place | Scenes, levels, characters, assets, or navigation choreography |
| [GameBoy 8-bit portfolio](https://orpetron.com/sites/gameboy-8-bit-portfolio-matt/) | A constrained metaphor can unify navigation and presentation | Consistent controls and a disciplined pixel vocabulary | Hardware frame, console UI, palette, sprites, or nostalgic trade dress |
| Ordinary analytics dashboard or spreadsheet | Exact values remain easy to scan and compare | Direct access, explicit units, predictable filtering | Flat card accumulation with no narrative relationship |

## Synthesis

- Let real data determine the world; decoration never invents progress.
- Use one short route rather than simulating an entire game.
- Keep direct analysis available at every point through Free Roam.
- Make the metaphor explain interaction, not replace labels, units, dates, or tables.
- Treat originality as a system constraint: generic pixel 2D data-world shapes, no recognizable game or place.

## Positioning

Unlike a conventional dashboard or a game-themed portfolio, **AI Usage: The Endless Run** is a truthful usage report with an optional, non-modal path through its existing tool, model, and record states.

## Explicit exclusions

- No Beijing Second Ring Road or other identifiable city route.
- No copied game characters, tiles, worlds, devices, palettes, sounds, or trade dress.
- No XP, level, reward, achievement, rank, streak, or score language.
- No Canvas, game engine, physics, collision system, or custom rendering runtime.
