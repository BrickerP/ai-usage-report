# Round 4 — 可恢复的当前视图

## 自问

工具、模型和时间范围应该存进 localStorage、URL，还是只保留在当前会话？

## 自答与选择

- localStorage：自动但不可分享，且用户难以理解为何恢复旧状态。
- 当前会话：最简单，但刷新后探索上下文消失。
- URL：状态可见、可刷新、可分享，也符合分析视图携带上下文的常见做法。

选择 URL，并使用 `replaceState`，避免每次聚焦都污染浏览器后退栈。

## 落地

- `tool`、`model`、预设时间范围写入查询参数；自定义时间用 `from` / `to`。
- 默认 30 天不写冗余参数。
- 首次载入后按真实工具和模型数据校验参数；无效值安全回落。
- 保留页面已有的无关查询参数。

## 验证与反思

纯函数测试覆盖往返、自定义日期、边界收敛和无效参数。URL 只保存“当前视图”，没有触碰 Codex / Cursor / Claude Code / One API 的数据口径。
