# Round 7 — 工具卡只保留一个下一步

## 假设

工具卡同时展示总量、token 组成、模型数量、全部模型名称、每个模型 tokens 与费用，已经承担了模型详情页的工作。置信度：95%。

## 自问

模型预览应该保留前几个、折叠起来，还是从工具卡移除？

## 自答与选择

- 保留前几个：仍会制造不一致的“为什么只看到这些模型”。
- 卡内折叠：给四张卡各增加一个局部状态，交互反而更复杂。
- 从卡片移除：卡片只回答“这个工具用了多少、由什么 token 构成、下一步去哪”。

选择移除模型库存。完整模型仍可在图表的 `All models` 详情中查看和聚焦。

## 落地

- 删除四张工具卡中永久展开的模型行。
- 保留 identified model 数量。
- 保留唯一的 `View models` / `Viewing` 操作，以及 `aria-pressed`、工具色、勾选状态和滚动到图表的行为。
- 没有改动 `summarizeRange`、`selectModelSeries` 或任何源数据。

## 反思

这轮没有把卡片整体做成按钮。保留明确的单一操作点，比扩大可点击面积更符合现有 Astryx 卡片语义，也避免点击数值时意外跳转。
