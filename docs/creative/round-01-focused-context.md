# Round 1 — Focused 模型与上下文

## 自问

聚焦一个模型后，图表应该只留下该模型、与“其他模型”做对比，还是保留所有模型并弱化非聚焦项？

## 自答与选择

- 只留一个模型：最干净，但失去异常发生时的组成背景。
- 与“其他”对比：可读，但引入新的聚合语义。
- 保留并弱化其他模型：不改口径，也能看出聚焦项在原上下文中的位置。

选择第三种。Focused 改变强调层级和费用序列，不改变其他模型 token 的可见性。

## 落地

- 标题、副文案和状态播报明确说明当前模型已聚焦。
- 非聚焦模型降至低透明度；费用线改为当前模型费用。
- 日期切换后若该历史模型在当前范围没有用量，仍保留一个 0 值 Focused series；费用保持为 0，不回退成工具总费用。
- 隐藏精确表格的费用列同步切换为当前模型，避免视觉图与辅助数据相互矛盾。
- ECharts 的无障碍描述同步表达“其他模型被弱化、费用跟随当前模型”。

## 验证与反思

单元测试覆盖视觉配置、费用列、零用量聚焦和可访问描述。真实浏览器狗粮测试发现 ECharts 会覆盖容器原有的 `aria-label`，因此最终描述放进 ECharts `aria.description`，而不依赖 React 容器属性。
