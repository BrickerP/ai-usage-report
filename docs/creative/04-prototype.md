# Token Skyline 原型（已批准）

## 一条核心旅程

打开 Explore → 浏览日常时间线 → 发现纪录日 → 读取 Sky 中的完整数字 → 选择工具或模型 → 两层图表与 tooltip 同步更新。

## 线框

```text
┌──────────────────────────────────────────────┐
│ RECORD SKY · 206亿        ◆ RECORD · 7/20     │
│                       ────◆────               │
├──────────── RECORD HORIZON ──────────────────┤
│ GROUND / TOKENS PER DAY                       │
│ ▂▃▂▅▃▂▂▆▃▂▃▂▂▅▂▃▂▂▃▂▂▅▂▃▂                  │
├──────────────────────────────────────────────┤
│ Spend / day                                   │
│ ▁▂▁▃▂▁▂▁▃▂▁▂▁▃▁▂                            │
└──────────────────────────────────────────────┘
```

Sky 和 Ground 使用同一日期轴、各自线性刻度。纪录日的堆叠段按 Horizon 拆分：Ground 显示基座，Sky 显示完整超出段；tooltip、隐藏表格和 aria 始终读取原始值。

## Design brief

- **主体题材**：个人 token 历史的城市天际线。
- **页面唯一工作**：让普通日可读，同时让纪录日成为可核验的成就焦点。
- **受众**：维护者本人和访问 GitHub Profile 的读者。
- **色彩角色**：沿用工具品牌色；Horizon 使用低饱和金色；Sky 只增加一枚金色 beacon。
- **字体角色**：沿用页面无衬线与等宽数字，不增加标题字体。
- **签名元素**：纪录日上方的菱形 beacon 与 `RECORD ·` 精确标签。

## 状态与边界

- 无极值时保持原来的单一 tokens 图层和 spend 图层。
- 有极值时才显示 Sky、Horizon 和 beacon，不增加按钮或新统计口径。
- Focused 模型会在两层同时保留高亮/弱化；点击 `Other` 仍打开模型清单。
- `prefers-reduced-motion` 下 beacon 静止，键盘和屏幕阅读器继续使用现有状态。
